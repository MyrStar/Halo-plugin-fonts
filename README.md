# Halo 字体管理插件（PluginFonts）

为 [Halo](https://halo.run) 2.x 提供全局字体管理能力：内置常用免费可商用字体库，支持自定义字体地址与 CDN 加速替换，并为访客提供前台字体切换浮窗。

## 功能特性

- **字体列表管理**：Console 侧「字体管理」页面，支持从预设库一键添加（思源黑体/宋体、霞鹜文楷、站酷系列、马善政毛笔、龙藏体等）、添加自定义字体（名称 + font-family + CSS 地址）
- **在线预览**：管理页与预设挑选弹窗中即时预览字体效果，预览文本可自定义
- **默认字体**：可将任一启用字体设为站点默认（或跟随主题不覆盖）
- **字体加速地址**：对字体 CSS 地址做主机替换（如 `fonts.googleapis.com` → `fonts.loli.net`），规则可增删、可单独开关
- **前台切换浮窗**：访客可通过页面悬浮按钮在已启用字体间切换，选择记忆在浏览器 localStorage 中，切换无闪烁（CSS 变量 + 预加载）
- **无需主题适配**：通过 `TemplateHeadProcessor` 注入资源，不依赖主题的 `halo:footer` 标签

## 环境要求

- Halo >= 2.22.0
- JDK 21（开发构建）

## 构建

```bash
cd ui && pnpm install && pnpm build && cd ..
./gradlew build
```

产物位于 `build/libs/plugin-fonts-*.jar`，在 Halo 后台「插件」页上传安装即可。

本地调试（自动启动 Halo 并加载本插件）：

```bash
./gradlew haloServer
```

## 使用说明

1. 安装并启用插件后，Console 左侧菜单「外观」分组出现「字体管理」
2. 在字体管理页添加字体（预设库或自定义），勾选启用，可设默认字体
3. 全局开关、加速地址规则、浮窗位置等配置在「插件 → 字体管理 → 设置」中修改
4. 前台页面自动注入启用字体；浮窗开启时访客可自行切换

### 关于字体加速地址

加速规则仅对字体 CSS 的入口地址做主机替换。请确保所用镜像站会改写 CSS 内部的字体文件地址（如 loli.net 系镜像），否则加速无效。本插件只做字符串替换，不会抓取任何远端内容。
