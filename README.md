# Halo Plugin Fonts

Halo 2.x 字体管理插件：后台可视化管理与预览字体、配置字体 CDN 加速地址、按字体独立设置字重，前台访客可通过浮窗在已启用的字体间自由切换。

## 功能特性

- **字体管理页面**：卡片式预览（可自定义预览文本），启用/停用、设为默认、编辑、删除
- **内置预设库**：12 款开箱即用的免费可商用字体（思源黑体/宋体、霞鹜文楷、站酷系列等），预设仅锁定名称与地址，字重可调
- **推荐字体库**：12 款来自 cn-fontsource（中文网字计划）与 npm CDN 的精选字体（得意黑、MiSans、阿里妈妈东方大楷、钉钉进步体等），一键添加为可自由编辑的自定义字体
- **自定义字体**：填入 font-family 与字体 CSS 地址即可接入任意 Web 字体
- **按字体独立字重**：每款字体可单独设置 400/500/600/700，解决部分字体偏细看不清的问题
- **字体加速地址**：对字体 CSS 地址做主机映射替换（如 googleapis → loli.net、jsdelivr → fastly），镜像站需会改写 CSS 内部字体文件地址
- **前台切换浮窗**：访客选择记忆在浏览器 localStorage，支持四个角落位置与自定义提示文字
- **精细作用范围**：可配置字体作用的 CSS 选择器（每行一个），避免污染代码块等宽字体
- **按需加载**：仅注入已启用字体的 CSS，中文 Web 字体按 unicode-range 分包，首屏只下载实际用到的分片

## 环境要求

- Halo >= 2.22.0

## 安装

1. 在 Releases 下载最新的 `plugin-fonts-x.y.z.jar`
2. Halo 后台 → 插件 → 安装插件 → 上传 jar → 启用

## 使用说明

### 字体管理（Console 左侧菜单）

- **从预设库添加**：弹窗分「内置预设 / 推荐字体」两个页签，悬停卡片即可加载真实字体预览，点击添加
- **添加自定义字体**：填写名称、`font-family` 完整取值（建议带通用回退）、字体 CSS 地址（`@font-face` 所在样式表）
- **设为默认**：全站默认使用该字体；「恢复跟随主题」则不覆盖主题字体
- **字重**：编辑任意字体可设置字重，仅作用于该字体；单字重字体设置更高字重时由浏览器合成加粗

### 全局设置（插件设置页）

| 配置项 | 说明 |
|---|---|
| 预加载所有启用字体的 CSS | 开启后访客切换字体无网络延迟；关闭则仅加载默认字体 |
| 字体加速地址规则 | 主机映射替换，可增删多条并单独启停 |
| 前台字体切换浮窗 | 开关、位置（四角）、按钮提示文字 |
| 字体作用选择器 | 每行一个 CSS 选择器，默认 `body`；请勿包含 `code`、`pre` 等代码元素 |

### 前台浮窗

访客点击悬浮按钮（默认右下角「Aa」）即可在「站点默认」与所有已启用字体间切换，选择记忆在访客浏览器中。

## 内置字体清单

**预设**：思源黑体/宋体（简/繁）、霞鹜文楷（屏幕阅读版）、站酷小薇体、站酷快乐体、站酷庆科黄油体、马善政毛笔、刘健毛草体、志莽行书、龙藏体

**推荐**：得意黑、阿里妈妈东方大楷、钉钉进步体、霞鹜新晰黑、霞鹜漫黑、MiSans、悠哉字体、小赖字体、鸿雷行书、猫啃珠圆体、975 圆体、霞鹜文楷（原版）

所有字体均可免费商用，CSS 地址经过加速规则转换。

## 本地开发

```bash
# 构建 Console 前端
cd ui && pnpm install && pnpm build

# 构建插件 jar（产物在 build/libs）
./gradlew clean build -x test
```

技术栈：pf4j + Spring WebFlux（CustomEndpoint / TemplateHeadProcessor）+ Vue 3（`@halo-dev/ui-plugin-bundler-kit` IIFE 构建）。字体列表存储于插件 ConfigMap，设置实时读取、保存即生效。
